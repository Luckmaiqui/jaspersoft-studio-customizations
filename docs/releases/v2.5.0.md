# Versão 2.5.0

- Ctrl+F reconhece o JasperServer selecionado, inclusive a partir de uma pasta ou arquivo descendente, e abre a pesquisa com essa conexão no escopo.
- A mesma janela permite pesquisar todos os servidores, um servidor ou vários marcados em Escolher Servidores. Nenhuma conexão é consultada antes de clicar em Pesquisar.
- Novos temas Salutem GitHub, Ônix e Meia-Noite, somando sete opções. Superfícies escuras e texto verificados com contraste mínimo 4,5:1.
- Corrige Java Bean e termos técnicos; Linguagem nos campos de programação, preservando Idioma na seleção do idioma da interface; Banco de Dados na categoria de conexões.
- Padroniza as iniciais dos rótulos e campos, mantendo artigos e preposições em minúsculas, nomes técnicos, parâmetros e valores editáveis.
- Menus de contexto usam desenho nativo escuro do Windows, sem o relevo duplo dos itens desabilitados. Os comandos continuam desabilitados quando aplicável. Rótulos desabilitados por herança também recebem pintura em uma passagem.

Validação: testes SWT de contexto, escopo múltiplo e independência dos exploradores; agregação/cancelamento; sete paletas; rótulos herdados; preservação de comandos, atalhos, listeners e valores técnicos; 49 recursos/6.496 chaves com parâmetros preservados. Comparação visual reproduziu o texto em relevo com cores forçadas e confirmou a correção com desenho nativo escuro.

Os três componentes seguem independentes. Atualize apenas os desejados e reinicie o Studio após salvar o trabalho. Compatibilidade: Community 6.20.6, Windows, Java 17+.
