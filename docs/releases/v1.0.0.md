# Tradução e Tema JS 1.0.0

Pacote para **Jaspersoft Studio Community 6.20.6 no Windows**, com Java 17 ou superior.

- Salutem Noite 1.7.5: paleta azul escura, contraste e tratamentos de componentes.
- Português (Brasil) 2.0.2: recursos de 24 módulos, rótulos complementares e bandeira.
- Ordenação numérica das conexões 1.0.0.
- Instalador portátil com validação de versão e SHA256.
- Correções do botão Salvar e do progresso da publicação.

Extraia o ZIP, feche o Studio e execute `Instalar.bat`. Depois use `Abrir JS.bat`. Em um workspace existente, escolha o tema Salutem Noite nas Preferências.

**Não é compatível diretamente com Studio 6.16**, Linux, macOS ou edição Professional. Consulte as instruções e as limitações no README. Os componentes foram testados separadamente; a aparência completa deve ser conferida no aplicativo após reiniciar.
